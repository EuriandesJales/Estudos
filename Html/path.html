O que é o Path?

Se refere a caminho, ese que é o caminho para os binarios do terminal, em outras palavra caminho para executaveis que são chamados por o terminal, é aqui estamos nós referindo a qualquer comando, pois todo comando no terminal nada mais é do que um script de código, desta forma, qualquer software adicionado ao sistema deverar ter anexado ao path um executavel para que o mesmo possa ser chamado e executado.

ATENÇÃO:

O path jamais deverar ser alterado, podemos anexar novos paths modificando o arquivo de configurações do terminal .bashrc ou o .zshrc dependendo do terminal que você usa, mas modificar o path, resultará em uma quebra do sistema operacional, onde ele não sabera onde esta os executaveis mesmo que se renomeio ou copie tudo, futuros softwares sempre estarão colocando seus executaveis dentro do path padrão /bin/bash

Como Anexar um path?

basta abrir o arquivo de configurações do terminal com o seu editor preferido vim, nano ou micro e adicionar 

export PATH=$PATH:/caminho/da/sua/pasta
desta forma qualquer scrip ou binario anexado neste repositorio será capaz de ser chamado como um camoando qualquer do terminal.
