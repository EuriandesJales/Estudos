O que é um Servidor de Git?

É um servidor que armazena projetos de git, como assim? git nada mais é do que um sistema que faz o controle de versão, sendo assim os arquivos gerados por esse sistema podem ser armazenados em diferentes servidores, aqui vai uma lista de servidores que armazenam projetos do Git

  1. GitHub

    2. Esse é o mais conhecido e utilizado, muitos profissionais fazem do git uma extensão do seu proprio curriculo

  2. Gitlab

    3. A preferencia dos programadores que usam conteiner por possui facilidades pra isso Gitlab é bem difundido na Comunidade Cientifica

  3. SourceForce

    4. Geralmente usado para armazenar codigo binario e projetos já finalizados
