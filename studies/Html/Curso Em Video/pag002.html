Links internos são de ABSOLUTA IMPORTANCIA a navegação é inteiramente feita sobre esse conceito e a implementação assim como a implementação de diversos recursos

Conceitos Importantes de indexação

Existe um parametro rel que determina o teor do link, usado em mecanismos de buscas para entender qual é o conteudo da pagina alguns exemplos de rel são:

Valores do Atributo rel e seus Significados

  • stylesheet - Define uma relação entre o documento e uma folha de estilos externa.
  • icon - Especifica um ícone para a página, geralmente usado em favicons.
  • nofollow - Indica para os motores de busca que não devem seguir o link. (geralmente usado para pubs)
  • noopener - Evita que a nova página aberta tenha acesso ao objeto window.opener, melhorando a segurança.
  • noreferrer - Evita que a página de destino receba informações sobre a página de origem.
  • alternate - Indica uma versão alternativa do conteúdo, como outro idioma ou formato.
  • author - Define um link para informações sobre o autor do documento.
  • canonical - Indica a URL preferida para evitar conteúdo duplicado.
  • prev - Indica a página anterior em uma sequência de navegação.
  • next - Indica a próxima página em uma sequência de navegação.
  • license - Define um link para informações sobre a licença do documento.
  • bookmark - Representa um link para um marcador dentro do site.
  • help - Indica um link para uma página de ajuda.
  • _self - links que levam para outra pagina no seu site.
