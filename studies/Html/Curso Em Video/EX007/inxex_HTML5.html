Diferenças entre HTML, CSS e Semântica

1. HTML (HyperText Markup Language)

O HTML é a linguagem de marcação usada para estruturar o conteúdo de uma página web. Ele define a hierarquia e o significado dos elementos no documento.

Características:

  • Cria a estrutura básica da página.
  • Usa tags para definir cabeçalhos, parágrafos, listas, links, imagens, etc.
  • Não possui estilo visual (cores, fontes, layout).

Exemplo de código:

<h1>Título da Página</h1>
<p>Este é um parágrafo em HTML.</p> Tags de textoss como <u> sublinhasr, <b> negrito <i> italico, porém que fique claro a usar essas tags html se chega ao proposito visual porém não semantico, para mecanismo de buscas ainda é claro o teor do seu site.

2. CSS (Cascading Style Sheets)

O CSS é usado para estilizar a página web, controlando cores, fontes, tamanhos e o layout de forma geral.

Características:

  • Controla o design visual da página.
  • Trabalha separado do HTML, mantendo a estrutura e o estilo desacoplados.
  • Suporta responsividade, adaptando o layout para diferentes dispositivos.

Exemplo de código:

body {
  background-color: #f4f4f9;
  color: #333;
} .negrito { font-weight: bold; } .italico { font-style: italic; } .sublinhado { text-decoration: underline; }

3. Semântica no HTML

HTML semântico utiliza tags que descrevem claramente o conteúdo, melhorando a acessibilidade e SEO (otimização para motores de busca).

Características:

  • Ajuda mecaTnismos de busca a entenderem a hierarquia e o conteúdo da página.
  • Melhora a acessibilidade para leitores de tela.
  • Torna o código mais organizado e fácil de manter.

Exemplo de tags semânticas:

  • <header>: Cabeçalho da página ou seção.
  • <nav>: Menu de navegação.
  • <article>: Conteúdo independente, como post de blog.
  • <section>: Seção de conteúdo relacionada.
  • <footer>: Rodapé da página.
    • <strong> : Que seria o Bold porém com significado semantico não apenas estetico <em> para ênfase ou expressão emocional. Use <u> só quando for nome próprio ou termo especial.
