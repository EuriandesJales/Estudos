
# Como usar executar esse projeto
## usar o `requirements.txt` para criar um ambiente virtual (venv)

Este projeto foi desenvolvido para praticar raspagem de dados (web scraping) e o uso de ambientes virtuais (venvs) em projetos Python. Seguindo os passos abaixo, você poderá configurar o ambiente necessário para executar o projeto.

## Passos para configurar o ambiente

1. **Criar o ambiente virtual**  
    No terminal, navegue até o diretório do projeto e execute o comando abaixo para criar um ambiente virtual chamado `venv`:
    ```bash
    python3 -m venv venv
    ```

2. **Ativar o ambiente virtual**  
    Após criar o ambiente virtual, ative-o com o comando apropriado para o seu sistema operacional:
    - **Linux/MacOS**:
      ```bash
      source venv/bin/activate
      ```
    - **Windows**:
      ```bash
      venv\Scripts\activate
      ```

3. **Instalar as dependências**  
    Com o ambiente virtual ativado, instale as dependências listadas no arquivo `requirements.txt`:
    ```bash
    pip install -r requirements.txt
    ```

4. **Executar o projeto**  
    Agora o ambiente está configurado e você pode executar o projeto normalmente.
