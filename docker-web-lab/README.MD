# Docker Web Lab

Este projeto consiste na orquestração de uma stack Web completa utilizando **Docker Compose** para simular ambientes produtivos.

## 🚀 O que este laboratório faz:
*   Sobe uma stack **WordPress** integrada a um banco de dados **MySQL/SQL**.
*   Configura **redes isoladas** para garantir a comunicação segura entre os containers.
*   Implementa **volumes persistentes** para garantir que os dados do site e do banco não sejam perdidos.

## 🛠️ Como usar:
1.  Clone o repositório.
2.  Execute `docker-compose up -d`.
3.  Acesse `localhost:8080` no seu navegador.
